# plans/ index — the corpus manifest

The manifest over the plans/ corpus — the 108 pre-constitution documents 0001–0109 (0028 deliberately deleted; see [Anomalies](#anomalies)), plus the post-baseline documents 0110– ruled under the constitution — and the **one maintained file** in this directory. The numbered documents themselves are immutable history under the "retired once obsolete, never maintained to track later changes" convention; that convention governs the documents, not this map. Originals stay byte-untouched: a document's status changes are recorded **here**, never stamped onto the document.

The columns lean on two companions:

- [docs/principles.md](../docs/principles.md) — the design-principles constitution. The `principles` column names the P-ids the document's rulings derive from.
- [docs/releases.md](../docs/releases.md) — the version spine. The `release` column names the release that carries the document's rulings; the whole corpus 0001–0109 baselines `pre` and is never retroactively versioned.

## Status vocabulary

- `active-authority` — the document's rulings still govern; where a later document re-ruled part of it, the row says so and the remainder stands.
- `superseded-by NNNN` — the named later document replaced this one's governing role; the original remains as history.
- `historical-only` — the document records work that has run its course (absorbed, executed, or archived); it binds nothing, kept for traceability.
