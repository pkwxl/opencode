## The ruling

**D1 — the switch classified, not retired.** `OPENCODE_AUTO_ANALYSIS` stays as it is: default on,
`=off` the floor. The mechanism is standing law in every way but the switch's name — 0101, 0114,
0115 and 0133 all build on it — but the switch earns its keep as the escape hatch (a field defect
in the flow should not need a binary rollback), and `=off`'s only real consumer is the e2e suite.
The classification is now stated where the person reads it: `=off` is the test/recovery floor, not
a supported way of working — the project then starts with no brief (the analysis release is the
start's only approval channel; `amend --brief` the manual word until then, and a leading survey
phase's release still installs one on the re-work bundles).

**D2 — the off-corner's notice tells the truth.** The no-brief planning notice fires, in practice,
only in the `=off` world — the analysis gate installs the brief before either on-world call site
can reach it — so naming "the project analysis's proposal" there pointed at a channel that cannot
run. The notice is now conditioned on the switch: the on variant keeps the designed-channel text
(true for the pathological mid-life-deletion corner), the off variant says why no approval will
install one and names the two working channels (`amend --brief`, the planning input). P12 — a
degraded corner's message names its own world's remedies.

**D3 — the authority order, one picture.** The glossary now carries the composed map beside the
brief entries: the intent charter and the specification notes outrank every prompt; beneath them
the person's latest approved words — the project brief for the project's constants, the round
brief for the round's scope, newest approval winning within each — then the approved analysis as
standing background (its settled lines binding where no later approval touched); then the planning
input; then prompt blocks. A lower document may narrow the charter's walls and permissions, never
widen them. Each surface's local statement (the charter's precedence block, the surveys'
newest-first line, the round-brief duty) stays as its own teacher; the map is the composed record.
