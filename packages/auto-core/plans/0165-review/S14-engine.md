## Design notes

- **Health:** the engine is the best-structured layer reviewed so far. It has one queue, a declarative arbitration table with a type-checked row per input, per-slice ownership (enforced by type and by a runtime fx audit), a byte-pinned trace oracle and a replay proof over the run-events journal. The spine's own logic held under every lens.
- **Worst choice:** at its edges the engine decides by text and by connection existence instead of structured facts. Examples: the restart regex that silently rotted (S14-01), the probe that asks "does the server answer" instead of "is my stream alive" (S14-05), and the late step-up re-reading a turn-accumulated message (S14-02).
- **The trace goldens** freeze the pre-engine behavior as stage D's equivalence proof. They pin the implementation, defects included (S14-04's missing abort is golden). Now that the engine is the reference, a ruling should re-bless a golden deliberately rather than treat it as the spec.
