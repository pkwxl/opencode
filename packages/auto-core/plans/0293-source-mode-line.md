## The enactment

- **The resolution** — `resolvedLine()`: the stamped commit when stamped;
  else the tool tree's own `git rev-parse --short HEAD` anchored at
  version.ts's directory, a `+dirty` suffix when
  `git --no-optional-locks status --porcelain` is non-empty, `dev` when
  git cannot name the tree ($bunfs guarded — a compiled binary never
  spawns). One home, every surface reading it.
- **The witness** — /health carries `line` (the daemon's own resolution,
  captured once at `startDaemon`: a process's module graph never moves)
  beside `checkout` (a fresh resolution per read). Equal: nothing owed.
  Divergent: the checkout has moved under a still-running daemon — the
  source-mode staleness window, its remedy the restart. A compiled binary
  reads its stamp for both, no spawn, the fields constant.
- **The carriers** — the serve banner prints the resolved line (a source
  start names the tree's commit plus dirt, dating the process for the
  hand); the bridge worker resolves once per session at spawn and carries
  it on `ready`'s existing `build.commit` — so a freshly attached bridge
  naming a later line than the daemon's `/health` `line` exhibits the
  same skew from the other side (the residual's "name both lines" letter).
  Never re-read per request within a live process: a fresh read would
  claim code the process is not running.

## Declined

Family (ii) — the daemon watching its own tree and exiting loudly on
change: a standing file watcher is machinery the witness obviates, and an
self-exiting daemon surprises the estate's supervisor posture (0290's
host-side note — the watcher-respawn question is the estate's, not the
tool's). Family (iii) — per-invocation op processes: the operations are
in-process library calls by design (P5 — the coordinator's ledger has one
writer; the ops' cost profile is a request/response), and a process per op
would re-open the ledger per act. Carrying `budget` on verify/fix grants
is 0294's next-door letter, not this ruling's.

## Residuals

The dirty suffix is coarse — any dirt anywhere in the tool repository
names itself, never a per-file relevance claim (the honest cheap read).
The comparison is the operator's act: nothing polls /health on the
tool's behalf (the estate's watcher may). The bridge handshake's line is
per-spawn truth; a session outliving a checkout move still serves its
spawn-time modules — bounded by the lease clock and the idle shutdown,
unchanged.

## Site-side

The next source-mode daemon restart onto this line prints its tree's
commit in the banner; the estate's operator (or watcher) polls /health
and compares `line` with `checkout` after every landing — the four-hour
silent window cannot recur unseen. The demolition track's marker, at
(0293+) by 0292's ruling, shifts to (0294+) by this ruling's landing.
