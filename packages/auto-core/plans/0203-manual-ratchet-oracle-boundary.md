## D1 — the oracle over prompt copy is text-level, and its unit is the ruled relationship

**The ruling.** What the manual ratchet pins, for each ruled relationship, is the complete
text-level hold: (a) the manual sentence that states the rule (verbatim, whitespace-normalized),
(b) the retired defective sentence pinned **absent**, (c) the frozen literals, and (d) — D2 below —
the driver-side producer line the statement mirrors. The unit is the relationship, not the
vocabulary item: a pin that holds a literal while either the sentence around it or the derivation
it names can drift is the measured defect (0165's green 37 over nine defects).

**Scenario execution is declined.** The three shapes considered, each on grounds:

- **A prose-rule interpreter in the test** (fixture states plus a mechanism that "applies the
  prompt's rule" and checks the outcome — the finding's "deterministic protocol traces" read
  literally): prompt copy has no interpreter. The mechanism would re-state the rule in test code,
  and the assertion would measure the re-statement, never the prompt — an oracle that cannot read
  the artifact it guards is not evidence over that artifact (P19). Where the rule mirrors driver
  semantics, a test-side re-statement is additionally a mirror of the one owning implementation
  (P5) — a third statement of the rule beside the driver's code and the prompt's prose, agreeing
  with neither by construction.
- **Re-running the driver's exported functions over the canonical fixtures inside this ratchet**:
  the pure derivations' behavior already has its one test home each (named above). Duplicating
  those runs here pays redundancy without holding any new fact about the manual copy (P21 — the
  machinery's consumer is the coupling, and the coupling is held textually against both sides at a
  fraction of the surface); the canonical scenarios (zero shares → 1; past `fix 1.1` → 2; sparse
  indices stay sparse; ticked P01 never wins over unticked P02; `S01/done.md` + `S02/todo.md`
  legal, both-files illegal; the freeform list that is two entries to prose and zero to the count)
  already live in those homes' cases and in the rulings' prose.
- **An LLM-judged evaluation of the prompts** (does a reading session apply the rule right?):
  non-deterministic — outside the corpus's ratchet discipline, every ratchet in this repository a
  deterministic pin (P12's measurable-oracle floor). The reading session's application of a
  correctly-stated rule is the suite's design premise, not a testable property of the copy.

## D3 — the named ceiling, and the revisit trigger

**The ceiling.** The manual suite's own choreography rules have no driver twin to couple — the
verdict reply channel (`Verification: PASS` / `Verification: INCOMPLETE`, the suite's internal
vocabulary; no `src/` producer exists), the children-never-commit division, the re-entry
idempotence (0200 D4), the uncommitted-gaps lifecycle. Sentence pins are their ceiling, by design:
their execution is the reading session's act, checked downstream by git history and the person —
no driver code parses the manual master's artifacts, so no executable counterpart exists anywhere,
and the ratchet holds the ruled statement alone. This is not a gap to close but the suite's shape:
a person-scale driver whose guard is its own pinned statements plus the git history it produces.

**The revisit trigger.** A measured incident where a pinned manual sentence and the driver's
semantics diverged through a driver-side change that D2's producer pins could not see — a semantics
change leaving every pinned producer line intact. That would be the evidence for executable
coupling arms (the driver's exported functions run over the canonical fixtures beside the pins),
and the shape is named here so the trigger's answer is mechanical, not new design.

**The finding's four evidence clauses, dispositioned.** max+1 → 0201 D1's sentence pins + coupling
2; gap grammar → 0201 D2's sentence pins + coupling 4; resume's state gate and ticked-phase
selection → 0200 D2/D3's sentence pins + couplings 7 and 8, the scenario-execution half declined
here with grounds (D1); the bundle join → 0177 D1 (landed, re-read). The sentence pins'
fail-before proofs were steps 040–042's; the couplings' fail-before is this step's (the drifted
producers, every previously-pinned literal intact, HEAD's ratchet green over each drift — the
blindness demonstrated — the new arms red).
