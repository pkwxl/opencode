## The enactment

- **(a) The `step` key named.** The reply-envelope paragraph states the
  acts' payload shapes — `ready`'s `{ build, menu }`, every other act's
  `{ step }` — and the claim letter names the key. The site's first parse
  read a `grant` key against a good reply; the spec now names the field
  the wire has always carried. No code change: the wire was right, the
  letter was absent.
- **(b) The budgetless verify clock documented.** The heartbeat letter
  states the derivation's true shape: the renewal window derives from the
  lease's own budget (0260) which **the coordinator's ledger holds** —
  verify and fix grants carry no `budget` on the wire, their shares
  living on `deadline` and the menu's renewed lease rows. Carrying the
  field on the follow-up arms declined: the hub consumes deadlines, the
  coordinator holds the clock, and a redundant field is a second source
  (P5). The wire pin rides the new serialization suite.
- **(c) The not-ready cause class.** The 260 site's bare
  `"T-006 is not ready."` splits into four mechanical classes, each
  reading state the derivation already holds: the route equal to the
  ledger's continuation unit names the pin and teaches its releases (the
  person's Status amendment or completion, or a takeover share); a routed
  task with unmet dependencies names the edges (`unmetDepends`, the same
  `readyDone` home the routing reads); a target the plan does not carry
  names its absence; anything else names the index's own status. The held
  row inherits (it copies the detail verbatim), closing the field's
  measured indistinguishability — the ledger's pin and the dependency
  wait diagnosable apart on the menu alone.
- **(d) The landed context.** An execute grant over a unit with a landed
  share carries `landed: { id, commit }` — the prior share's id and its
  landing commit, attached at the coordinator's grant assembly from
  `lastLanded` (0276's per-unit context discipline, the fix grant's
  `phase`/`index`/`findings` the precedent). A takeover or continuation
  holder reads its unit's already-landed state from the grant, not the
  tree — the field record's F4d. A fresh unit carries nothing: the key
  itself absent on the wire, the byte-identical floor.
