# 0296 — The opencode severance: `opencode.json` never ours, the pull-mode-only surfaces purged

Status: **enacted, 2026-11-22, in four slices** (the process/template
severance, the protocol's model-free letters + the server's repair, the
manual floor `executor.md` + the push prompt suite's retirement, the models
surface's removal — this document and its docs companions the fifth). The
person ruled past 0295's remedy families: the record's seeds are not to be
patched but **removed past** — the tool's opencode-referencing surfaces
leave the corpus whole, the file's ownership settles with the host, and the
program's direction names its end state: a pull-mode-only tool. Each slice
landed category-complete per 0123/0110 D13; this document records the
ruling, the census the slices enacted against, the amendments, and the
docket the severance leaves standing.

## The person's ruling (recorded)

- **The file `opencode.json` is never the tool's related file.** Not a
  committed project surface, not an init write, not a fix surface, not an
  ignore-set entry, not a protected driver state, not a fence name — the
  tool writes, reads, ignores, protects, and names it nowhere. The host's
  configuration file is the host's own; a person editing theirs mid-run is
  editing their own file; a grant writing it is out of scope by the
  ordinary rule, never by a named never-refusal.
- **The goal is a pull-mode-only tool.** Any opencode-related things are
  removed from protocol, prompts, templates, and process — the push-era
  surfaces that still taught opencode-session carriage (0295's seeds) go
  whole, not marked.
- **The models surface is removed entirely** — the CLI `models` command,
  the daemon's GET/POST `/projects/<project>/models` arms, the boot-time
  registry validation, the `probe` scope: **the tool spawns no agent
  session, ever.** The agents that work a project are external coding
  agents claiming grants, each bringing its own model.
- **The identity rename is deferred to 0256 stage 7.** The bins, the
  package names, the `OPENCODE_AUTO_*` env prefix, the `.opencode/auto/`
  home, and the AGENTS.md markers stay self-references until then; nothing
  in this ruling renames them.
- **The push manual prompt suite is retired** — `prompts/executor.md`,
  refreshed against the live wire, is the manual floor alone.
